# PM Role

Responsibilities:

- confirm the correct worktree and scope before coding starts
- inspect code, repo structure, and README before planning
- write a scoped plan to `plans/`
- decide whether the task stays in one lane or needs delegated sub-work
- define validation and report requirements before implementation
- close the loop with a final report in `reports/`

Outputs:

- one plan file per substantive task
- one final report per substantive task
- explicit file list, validation commands, and unresolved risks
